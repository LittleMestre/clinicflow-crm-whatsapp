# ClinicFlow — CRM SaaS + WhatsApp Business API

**CRM full stack para clínicas e equipes de atendimento**, com foco em gestão de contatos, oportunidades e conversas.

![React](https://img.shields.io/badge/React-19-149eca?logo=react&logoColor=white) ![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6?logo=typescript&logoColor=white) ![Node.js](https://img.shields.io/badge/Node.js-20%2B-339933?logo=nodedotjs&logoColor=white) ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-16-4169e1?logo=postgresql&logoColor=white)

> **Estado:** repositório de portfólio em construção. A documentação inicial foi publicada, mas o código completo do MVP ainda não foi enviado a este repositório.

## Funcionalidades planejadas para o MVP

- **Dashboard:** indicadores de contatos, oportunidades e atividades.
- **Contatos:** cadastro, edição, busca e organização.
- **Pipeline:** acompanhamento visual das negociações.
- **Inbox:** conversas e histórico de mensagens.
- **WhatsApp Cloud API (Meta):** integração configurável, com modo de demonstração sem envios reais.
- **SaaS multi-tenant:** workspaces e separação de dados por organização.

## Stack

| Camada | Tecnologias |
|---|---|
| Frontend | React, TypeScript, Vite |
| Backend | Node.js, Express, TypeScript |
| Banco de dados | PostgreSQL |
| Mensageria | Meta WhatsApp Business Cloud API |
| Ambiente local | Docker Compose |

## Importante

O ClinicFlow é um **projeto demonstrativo**, não um software homologado para dados médicos ou uso em produção. A integração real com o WhatsApp requer credenciais válidas da Meta e medidas complementares de segurança, privacidade e conformidade com a LGPD.
